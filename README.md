# Трассировка LLVM IR

Решение на C: «Игра жизни» на SDL2 и сбор динамической трассы `User <- Operand` для `app.c` после оптимизации `-O2` и `-Os`. User `phi` пропускаются. Анализируются перекрывающиеся окна длиной 1–5 для инструкций и связей использования.

Проход реализован через LLVM C API и запускается отдельным драйвером после оптимизации.

## Запуск

```sh
make -j4
make run
make run OPT=Os
make stats
```

## Основные файлы

- `app.c`, `main.c` — логика приложения и окно SDL2.
- `pass.c`, `instrument.c`, `trace_runtime.c` — проход, драйвер и запись трассы.
- `analyze.c` — подсчёт паттернов.
- `stats/` — таблицы частот и [анализ результатов](stats/README.md).
