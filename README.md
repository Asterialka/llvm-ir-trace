# Трассировка LLVM IR: колония турмитов

Колония турмитов из первого задания с плагином Clang/LLVM, который встраивает пасс инструментации в пайплайн компилятора для сбора динамической трассы инструкций и её последующего анализа при `-O2` и `-Os`.

## Запуск

Запуск:

```sh
make -j4
make run
```

Для запуска с `-Os`: `make run OPT=Os`; для выхода закрой окно или нажми Escape.
