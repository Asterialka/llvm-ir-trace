# Анализ трассы LLVM IR

Колония турмитов, 64 кадра, LLVM/Clang 22.1.8. Инструментируется только
`app.c` при `-O2` и `-Os`; User `phi` пропускаются, Operand `phi` учитываются.
Собрано 35 199 042 связи `User <- Operand` для `-O2` и 59 840 790 для `-Os`.

Самые частые паттерны использования для перекрывающихся окон длиной 1–5
(при равной частоте показан один вариант):

| Длина | Паттерн `-O2` | Частота |
|---:|:---|---:|
| 1 | `call <- or` | 6 307 840 |
| 2 | `call <- or; call <- load` | 3 145 728 |
| 3 | `call <- or; call <- or; call <- load` | 2 359 296 |
| 4 | `call <- or; call <- load; call <- or; call <- or` | 2 359 296 |
| 5 | `call <- or; call <- load; call <- or; call <- or; call <- load` | 2 359 296 |

| Длина | Паттерн `-Os` | Частота |
|---:|:---|---:|
| 1 | `add <- phi` | 10 758 176 |
| 2 | `add <- phi; icmp <- add` | 5 515 272 |
| 3 | `add <- phi; icmp <- add; br <- icmp` | 5 515 272 |
| 4 | `add <- phi; icmp <- add; br <- icmp; add <- phi` | 4 988 928 |
| 5 | `add <- shl; call <- add; call <- add; call <- load; add <- phi` | 4 194 304 |

При `-O2` циклы отрисовки клетки развёрнуты: `call <- or` передаёт координаты
пикселя, `call <- load` — цвет. При `-Os` циклы сохранены, поэтому преобладают
связи счётчика и проверки условия: `add <- phi; icmp <- add; br <- icmp`.
Разворачивание циклов — основная причина уменьшения числа связей на 41,2% при `-O2`.

Полная статистика окон 1–5: [O2](O2/uses.tsv), [Os](Os/uses.tsv).
Трассы: [O2](O2/trace.bin.gz), [Os](Os/trace.bin.gz).
Повторный сбор: `make stats`.
